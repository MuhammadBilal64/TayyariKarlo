# Assessments visual direction — Ink & Graph (continued)

## Direction
Same quiet study-studio system as auth: graph-paper ground, deep ink type, forest-teal signal. Assessment screens stay inside the signed-in shell — focused exam desk, not a dashboard.

## Why this fits
- Continuity with login/workspace so prep feels one product.
- Serif for the question stem (exam paper), Sora for controls.
- Options are interactive rows (not card grids or pill clusters).

## Screens
- `setup.html` — pick topic, difficulty, question count; one Start CTA
- `take.html` — progress rule, one stem, selectable options, Next / Submit
- `results.html` — score as hero number, correct/incorrect, topic breakdown, CTAs

Reuse `../auth/tokens.css`.
