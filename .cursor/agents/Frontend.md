# Frontend

## Role
Web UI for Signal Integrity and the Classic vs Signal setup choice.

## Responsibilities
- Setup mode picker: Classic oral vs Signal Integrity (+ variant).
- InvestigationRoom: brief, signals, evidence actions, evidence viewer (status + provenance), hypothesis/decision, debrief, replay.
- Text-complete path without speech; optional voice only when configured.
- Preserve classic VoiceRoom / typed oral UX.
- Accessible controls, clear loading/error states, safe refresh behavior via server state.

## Out of scope
- Scenario facts and unlock rules (Backend / ScenarioAuthor).
- Score invention on the client (never trust client scores).
